# بيانات العائلات — Families Data

برنامج سطح مكتب لويندوز (10 أو أعلى) لجمع بيانات العائلات وفلترتها واختيار العائلات المستحقة للدعم.
يعمل **بدون إنترنت** بالكامل، وواجهته بثلاث لغات: **العربية، الإنجليزية، الأرمنية**.

## الميزات (الإصدار 0.1)

| الميزة | الوصف |
|---|---|
| تسجيل الدخول | اسم مستخدم وكلمة مرور، وثلاث صلاحيات: مدير / مُدخل بيانات / مشاهد. قفل تلقائي بعد عدم الاستخدام |
| العائلات | إضافة وتعديل بيانات رب الأسرة والأفراد (العمر يُحسب تلقائياً، إعاقة، مرض مزمن…)، وتنبيه عند تكرار الرقم الوطني |
| المعايير | إنشاء وتعديل وحذف معايير من داخل البرنامج: رقم، نص، نعم/لا، قائمة اختيار، تاريخ. لكل معيار نقاط لترتيب الأولوية |
| الفلترة | شروط مركّبة (كل الشروط / أي شرط) على الحقول الأساسية والمعايير وتاريخ آخر دعم، مع حفظ الفلاتر |
| الدعم | أنواع دعم قابلة للتعديل (مبلغ، كوبون، سلة غذائية، سلة صحية…)، وتسجيل الدعم لمجموعة عائلات دفعة واحدة، وسجل التوزيع |
| الأرشيف | نقل العائلة للأرشيف بسبب الوفاة أو السفر أو غيره، مع التفاصيل والتاريخ، وإمكانية الاستعادة |
| الإحصائيات | لوحة رئيسية: عدد العائلات والأفراد والأطفال والمسنين، والتوزيع حسب المنطقة والمعايير |
| النسخ الاحتياطي | نسخة تلقائية يومية (يُحتفظ بآخر 30)، ومجلد إضافي اختياري (فلاشة)، وتصدير واستيراد نسخة كاملة |
| Excel | تصدير النتائج، وقالب استيراد، واستيراد العائلات والأفراد |
| سجل العمليات | من أضاف أو عدّل أو حذف ومتى |

**الدخول لأول مرة:** اسم المستخدم `admin` وكلمة المرور `admin`، وسيطلب البرنامج تغييرها فوراً.

## مكان البيانات

- النسخة المثبّتة: `%APPDATA%\Families Data\data\families.db`، والنسخ الاحتياطية في `%APPDATA%\Families Data\backups`
- النسخة المحمولة (portable): مجلد `FamiliesData` بجانب ملف البرنامج

## للمطوّرين

```bash
npm install
npm start          # تشغيل البرنامج
npm test           # الاختبارات
npm run dist:win   # بناء ملف التثبيت (على ويندوز)
```

عند كل رفع (push) إلى GitHub يقوم GitHub Actions ببناء ملف التثبيت لويندوز تلقائياً (Actions → Build Windows installer → Artifacts).

### البنية

- `src/main/db.js` قاعدة بيانات SQLite (sql.js، بدون مكتبات أصلية)
- `src/main/service.js` منطق العمل: المستخدمون، العائلات، المعايير، الفلترة، النقاط، الإحصائيات
- `src/main/backup.js` النسخ الاحتياطي والاستيراد والتصدير
- `src/main/excel.js` استيراد وتصدير Excel
- `src/main/main.js` نافذة Electron وقنوات الاتصال
- `src/renderer/` الواجهة (`i18n.js` للترجمات الثلاث)

## المراحل القادمة

- قراءة بيانات الهوية من الصورة (OCR) أو من الباركود (بانتظار عيّنة الهوية)
- إضافة المعايير والإحصائيات النهائية عند إرسالها
- تشفير ملف قاعدة البيانات
